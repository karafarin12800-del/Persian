# Persia War — Unity 2.5D

این شاخه پایه بازسازی پروژه Persia War با Unity است.

## هدف
- بازسازی هسته بازی از صفر با Unity
- حفظ و استفاده مجدد از Assetهای اصلی پروژه Android
- دوربین 2.5D ایزومتریک/پرزسپکتیو با عمق واقعی
- کنترل لمسی Android
- بازیکن، دشمن، شلیک، نارنجک، Pickup و HUD
- معماری قابل توسعه برای مراحل و Multiplayer آینده

## ساختار
- `Assets/Scenes` — صحنه‌های بازی
- `Assets/Scripts` — منطق بازی
- `Assets/Prefabs` — Prefabها
- `Assets/Art` — Assetهای واردشده و آماده‌سازی‌شده
- `Assets/UI` — رابط کاربری
- `ProjectSettings` — تنظیمات Unity

> این شاخه به‌صورت مستقل از نسخه Android نگهداری می‌شود. شاخه `main` نسخه قبلی Android است.
