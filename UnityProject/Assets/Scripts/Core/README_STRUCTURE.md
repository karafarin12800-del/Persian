# مرحله اول Unity 2.5D

این مرحله هسته را عمداً ساده نگه می‌دارد تا قبل از انتقال کامل Assetها، معماری قابل تست باشد.

## قرارداد صحنه
- World: محور X/Z برای حرکت و نقشه
- Y: ارتفاع و عمق بصری
- Camera: نمای سه‌ربع 2.5D
- Player: GameObject مستقل با PlayerController
- Combat: WeaponController مستقل از حرکت

## انتقال Asset
منبع اصلی Assetها در نسخه Android فعلی باقی می‌ماند. فایل manifest پروژه قبلی فهرست Assetهای اصلی را مشخص کرده است. در مرحله بعد Assetهای واقعی به `Assets/Art/Imported` منتقل و Sprite Sheet پادشاه به چند Animation Clip تقسیم می‌شود.

## هدف تست اول
1. اجرای Scene بدون خطای اسکریپت
2. حرکت بازیکن روی محور X/Z
3. دنبال‌کردن نرم دوربین
4. آماده بودن ورودی لمسی برای اتصال Joystick UI
5. سپس اضافه‌شدن شلیک، دشمن و نقشه واقعی
