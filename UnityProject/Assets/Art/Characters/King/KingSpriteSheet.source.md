# King Sprite Sheet

Source asset is copied from the existing Android project's `app/src/main/assets/player/king_sprite_sheet.png` into the Unity branch using the same Git blob.

- Source dimensions: 6144 × 4096
- Layout: 6 frames × 4 directions
- Intended Unity import mode: Multiple / Sprite (2D and UI)
- Pixels Per Unit: 256 (initial value; tune after visual inspection)
- Filter Mode: Point for pixel-art presentation
- Compression: None

The binary source is intentionally kept identical to the Android asset; Unity import settings should be stored in the generated `.meta` file by Unity Editor.
