# Renderer status

This branch is intentionally limited to presentation architecture. Existing gameplay systems are not being expanded or given new weapon-related functionality.

## Target
A stable Android 2.5D scene renderer with:
- real camera/projection transforms,
- depth sorting by ground anchor,
- billboard characters,
- world-space building assets,
- soft contact shadows,
- screen-space HUD and controls.

## Asset policy
Use the existing repository assets first. New artwork is only needed when an existing asset category is genuinely missing.
