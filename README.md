# PersiaWar2D

A 2D top-down Persian/Achaemenid Android action-game prototype.

## Current core
- Touch joystick movement
- Touch aiming and FIRE control
- Enemy waves and basic AI
- Player/enemy shooting and collisions
- Health, score, wave progression and Game Over
- Landscape Android layout
- Achaemenid/Persian visual placeholders
- Character selection and radar overlay

## Build
The project uses Android SDK 35, Java 17 and Gradle 8.7. GitHub Actions builds a debug APK on pushes to `main` and via manual dispatch.
