# PersiaWar2D

نمونه اولیه بازی اکشن دوبعدی از بالا برای Android با فضای ایرانی/هخامنشی.

### هسته فعلی
- حرکت با جوی‌استیک لمسی
- هدف‌گیری و شلیک لمسی
- موج‌های دشمن و هوش ساده دشمن
- برخورد گلوله و برخورد مستقیم
- جان، امتیاز، موج و Game Over
- حالت افقی برای موبایل
- محیط و شخصیت‌های Placeholder با هویت ایرانی
- انتخاب شخصیت و Radar Overlay

### مسیر توسعه
1. تست APK و رفع خطاهای اجرای واقعی
2. دوربین و نقشه قابل گسترش
3. موانع و Collision دقیق‌تر
4. انواع دشمن و سلاح
5. انیمیشن و Assetهای نهایی هخامنشی
6. سیستم مرحله و مأموریت
7. ذخیره بازی
8. در صورت پایداری هسته، Multiplayer
